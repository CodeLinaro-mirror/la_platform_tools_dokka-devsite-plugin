BottomAppBarScrollBehavior

View Source
  • Cmn
    @ExperimentalMaterial3Api
    interface BottomAppBarScrollBehavior

A BottomAppBarScrollBehavior defines how a bottom app bar should behave when the content under it is scrolled.
