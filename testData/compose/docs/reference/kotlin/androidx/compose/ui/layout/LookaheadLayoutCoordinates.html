This interface is deprecated.
LookaheadLayoutCoordinates class has been removed. localLookaheadPositionOfcan be achieved in LookaheadScope using LayoutCoordinates.localLookaheadPositionOf(LayoutCoordinates) function.

LookaheadLayoutCoordinates interface holds layout coordinates from both the lookahead calculation and the post-lookahead layout pass.
