FocusPropertiesModifierNode

@ExperimentalComposeUiApi
interface FocusPropertiesModifierNode : DelegatableNode

Implement this interface create a modifier node that can be used to modify the focus properties of the associated FocusTargetModifierNode.

fun modifyFocusProperties(focusProperties: FocusProperties): Unit

A parent can modify the focus properties associated with the nearest FocusTargetModifierNode child node. If a FocusTargetModifierNode has multiple parent FocusPropertiesModifierNodes, properties set by a parent higher up in the hierarchy overwrite properties set by those that are lower in the hierarchy.
