FocusTargetModifierNode

@ExperimentalComposeUiApi
class FocusTargetModifierNode : Modifier.Node, ObserverNode, ModifierLocalNode

kotlin.Any
   ↳ androidx.compose.ui.Modifier.Node
     ↳ androidx.compose.ui.focus.FocusTargetModifierNode

This modifier node can be used to create a modifier that makes a component focusable. Use a different instance of FocusTargetModifierNode for each focusable component.
