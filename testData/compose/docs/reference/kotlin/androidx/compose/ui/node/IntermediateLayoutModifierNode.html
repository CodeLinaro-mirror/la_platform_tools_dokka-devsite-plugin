IntermediateLayoutModifierNode

@ExperimentalComposeUiApi
interface IntermediateLayoutModifierNode : LayoutModifierNode

IntermediateLayoutModifier is a LayoutModifierNode that will be skipped when looking ahead. During measure pass, measure will be invoked with the constraints from the look-ahead, as well as the target size.
