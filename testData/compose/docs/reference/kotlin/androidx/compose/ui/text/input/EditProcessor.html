EditProcessor

View Source
  • Cmn
    class EditProcessor

Helper class to apply EditCommands on an internal buffer. Used by TextField Composable to combine TextFieldValue lifecycle with the editing operations.

  • When a TextFieldValue is suggested by the developer, reset should be called.

  • When TextInputService provides EditCommands, they should be applied to the internal buffer using apply.
