KeyboardActions

class KeyboardActions

The KeyboardActions class allows developers to specify actions that will be triggered in response to users triggering IME action on the software keyboard.

onDone

val onDone: KeyboardActionScope.() -> Unit

This is run when the user triggers the ImeAction.Done action. A null value indicates that the default implementation if any, should be executed.

onGo

val onGo: KeyboardActionScope.() -> Unit

onNext

val onNext: KeyboardActionScope.() -> Unit

This is run when the user triggers the ImeAction.Next action. A null value indicates that the default implementation should be executed. The default implementation moves focus to the next item in the focus traversal order.

See androidx.compose.ui.focus.focusOrder for more details on how to specify a custom focus order if needed.

onPrevious

val onPrevious: KeyboardActionScope.() -> Unit

This is run when the user triggers the ImeAction.Previous action. A null value indicates that the default implementation should be executed. The default implementation moves focus to the previous item in the focus traversal order.

See androidx.compose.ui.focus.focusOrder for more details on how to specify a custom focus order if needed.
