fillParentMaxHeight

fun <ERROR CLASS>.fillParentMaxHeight(fraction: Float = 1f): <ERROR CLASS>

Have the content fill the Constraints.maxHeight of the incoming measurement constraints by setting the Constraints.minHeight to be equal to the Constraints.maxHeight multiplied by fraction. Note that, by default, the fraction is 1, so the modifier will make the content fill the whole parent height. fraction must be between 0 and 1.

Regular Modifier.fillMaxHeight can't work inside the scrolling vertically layouts as the items are measured with Constraints.Infinity as the constraints for the main axis.

fillParentMaxSize

fun <ERROR CLASS>.fillParentMaxSize(fraction: Float = 1f): <ERROR CLASS>

Have the content fill the Constraints.maxWidth and Constraints.maxHeight of the parent measurement constraints by setting the Constraints.minWidth to be equal to the Constraints.maxWidth multiplied by fraction and the Constraints.minHeight to be equal to the Constraints.maxHeight multiplied by fraction. Note that, by default, the fraction is 1, so the modifier will make the content fill the whole available space. fraction must be between 0 and 1.

Regular Modifier.fillMaxSize can't work inside the scrolling layouts as the items are measured with Constraints.Infinity as the constraints for the main axis.
