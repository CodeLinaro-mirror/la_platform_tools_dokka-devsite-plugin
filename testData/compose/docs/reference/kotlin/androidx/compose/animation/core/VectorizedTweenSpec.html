VectorizedTweenSpec

class VectorizedTweenSpec<V : AnimationVector> : VectorizedAnimationSpec, VectorizedFiniteAnimationSpec, VectorizedDurationBasedAnimationSpec

VectorizedTweenSpec animates a AnimationVector value by interpolating the start and end value, in the given durationMillis using the given easing curve.
