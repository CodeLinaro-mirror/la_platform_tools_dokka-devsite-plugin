public final class KeyboardActions

The KeyboardActions class allows developers to specify actions that will be triggered in response to users triggering IME action on the software keyboard.

onNext

@Nullable
public final @Nullable Function1<@NonNull KeyboardActionScope, Unit> onNext

This is run when the user triggers the ImeAction.Next action. A null value indicates that the default implementation should be executed. The default implementation moves focus to the next item in the focus traversal order.

See androidx.compose.ui.focus.focusOrder for more details on how to specify a custom focus order if needed.
