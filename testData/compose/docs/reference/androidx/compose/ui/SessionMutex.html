Helper class for coordinating between mutually-exclusive sessions. A session is represented as an object of type T and a coroutine Job whose lifetime is tied to the session.

Only one session can be active at a time. When a new session is started, the old session will be cancelled and allowed to finish any cancellation tasks (e.g. finally blocks) before the new session's coroutine starts.
