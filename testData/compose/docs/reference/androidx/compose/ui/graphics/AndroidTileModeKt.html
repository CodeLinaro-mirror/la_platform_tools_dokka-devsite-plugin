AndroidTileModeKt.isSupported

public static final boolean AndroidTileModeKt.isSupported(@NonNull TileMode receiver)

Helper method to determine if the appropriate TileMode is supported on the given Android API level this provides an opportunity for consumers to fallback on an alternative user experience for devices that do not support the corresponding blend mode. Usages of TileMode types that are not supported will fallback onto the default of TileMode.Clamp
