Create a PagedList which loads data from the provided data source on a background thread, posting updates to the main thread.

Returns
PagedList<T>

The newly created PagedList, which will page in data from the PagingSource as needed.
Parameters
K

Key type that indicates to the PagingSource what data to load.
T

Type of items to be held and loaded by the PagedList.
pagingSource

PagingSource providing data to the PagedList
notifyDispatcher

CoroutineDispatcher that will use and consume data from the PagedList. Generally, this is the UI/main thread.
fetchDispatcher

Data loading jobs will be dispatched to this CoroutineDispatcher - should be a background thread.
boundaryCallback

Optional boundary callback to attach to the list.
config

PagedList.Config, which defines how the PagedList will load data.
