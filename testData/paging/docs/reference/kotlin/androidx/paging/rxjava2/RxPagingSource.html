jumpingSupported

open val jumpingSupported: Boolean

true if this PagingSource supports jumping, false otherwise.

Override this to true if pseudo-fast scrolling via jumps is supported.

A jump occurs when a RecyclerView scrolls through a number of placeholders defined by PagingConfig.jumpThreshold and triggers a load with REFRESH.

PagingSources that support jumps should override getRefreshKey to return a RxPagingSource that would load data fulfilling the viewport given a user's current PagingState.anchorPosition.

See also
