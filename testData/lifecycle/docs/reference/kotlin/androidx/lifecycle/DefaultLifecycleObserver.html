DefaultLifecycleObserver

interface DefaultLifecycleObserver : LifecycleObserver

Callback interface for listening to LifecycleOwner state changes. If a class implements both this interface and LifecycleEventObserver, then methods of DefaultLifecycleObserver will be called first, and then followed by the call of onStateChanged

If a class implements this interface and in the same time uses OnLifecycleEvent, then annotations will be ignored.
